# Dependencias del proyecto

## Dependencias de producción

| Dependencia | Comando CMD de instalación |
|---|---|
| `@emailjs/browser` | `npm install @emailjs/browser` |
| `@fortawesome/fontawesome-free` | `npm install @fortawesome/fontawesome-free` |
| `axios` | `npm install axios` |
| `bootstrap` | `npm install bootstrap` |
| `bootstrap-icons` | `npm install bootstrap-icons` |
| `gsap` | `npm install gsap` |
| `sweetalert2` | `npm install sweetalert2` |

## Dependencias de desarrollo

| Dependencia | Comando CMD de instalación |
|---|---|
| `@eslint/js` | `npm install -D @eslint/js` |
| `eslint` | `npm install -D eslint` |
| `gh-pages` | `npm install -D gh-pages` |
| `sharp` | `npm install -D sharp` |
| `stylelint` | `npm install -D stylelint` |
| `stylelint-config-standard` | `npm install -D stylelint-config-standard` |
| `typescript` | `npm install -D typescript` |
| `typescript-eslint` | `npm install -D typescript-eslint` |
| `vite` | `npm install -D vite` |
| `vite-plugin-pwa` | `npm install -D vite-plugin-pwa` |

## Instalación completa del proyecto

```cmd
npm install
```
